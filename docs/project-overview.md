# Project Overview

## Purpose
Build an end-to-end data pipeline and analytics layer on ASOS product data, from raw ingestion through to retail insight.

## Scope
- Ingestion of raw product data into Azure SQL
- Cleaning and validation in Python
- Exploration, data quality checks, transformation and analytics in SQL

## Key questions
- What does the product catalogue look like by category, brand and price band?
- How complete and consistent is the data?
- Which pricing and discount patterns stand out?

## Tech stack
Python (pandas, SQLAlchemy, pyodbc), Azure SQL Database, SQL, Jupyter, pytest, Git/GitHub.

## Success criteria
- Reproducible pipeline from raw file to analytics tables
- Documented data quality rules and decisions
- Clear, queryable outputs
